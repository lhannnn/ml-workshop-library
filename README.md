# ML Workshop Library

A shared reference collection of **ICLR, ICML, and NeurIPS workshop programmes and publicly available workshop organization proposals**.

整理三大会议的 workshop 目录和公开组织提案，方便查阅主题、访问官网、阅读提案与比较历届办会内容。

**Catalogue snapshot: 2026-10-19.** This first release contains **322 research-workshop entries** and **5 saved proposal PDFs**, plus a supplementary index of **34 community and Expo events**.

- ICML 2026 includes **one cancelled workshop**, retained and labelled in the index.
- NeurIPS 2025 includes the San Diego and Mexico City research-workshop programmes.
- NeurIPS 2026 entries were **scheduled** at the snapshot date.
- [Community and Expo events](catalog/additional-events.md) are listed separately; this supplementary collection is not exhaustive.

Each conference index provides workshop titles, official or organizer links, and brief Chinese topic summaries. Titles and source links are intended to make the collection usable in either language. The summaries are editorial notes, not official abstracts.

## Sources and reusable data

- [Sources and coverage](SOURCES.md): official programme lists, snapshot date, and collection boundaries.
- [Proposal provenance](proposals/README.md): original PDF links and version notes.
- [Workshop catalogue JSON](data/workshops.json): all 322 research-workshop entries.
- [Additional events JSON](data/additional-events.json): the supplementary event index.
- [Proposal manifest](data/proposals.json): file paths, page counts, source URLs, and SHA-256 checksums.

For future additions, keep the conference and year, an authoritative source link, and a clear distinction between a programme entry and an archived proposal. For a new PDF, record its public source, download date, and checksum.

Third-party materials retain their original authorship and applicable terms; see [NOTICE.md](NOTICE.md).
