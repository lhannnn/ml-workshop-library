# ML Workshop Proposals

This repository collects official websites and original proposal PDFs for ICLR, ICML, and NeurIPS workshops in 2025–2026. Using Codex (GPT-6 Astra-Max), we searched public OpenReview pages and attachments, conference and workshop websites, and organizers’ GitHub repositories and commit histories, supplemented by broader web and GitHub searches. So far, we have found, verified, and included publicly available proposal PDFs for only a subset of the workshops.
